# argus v6.6.0 发布说明

**代号：语言能力面收口（Language Capability Convergence）**

起因：「支持语言 go ts js shell python 等等」要求好好收敛。实锤语言口径三套并存互斥
（README「Python/JS/TS」/ tech-debt「py/js 图层」/「funcdiff 扩 shell/py」），**rust/jvm/
c-family 全程文档隐身**（程序里早有解析器）；`get_repo_map` 已注册 MCP 工具但三处契约
文档全部漏载（宣称 23 工具、实际 24）。

## 核心变化

1. **`internal/langcap` 语言能力矩阵单一事实源**：图层 / funcdiff 词法面 / semsearch chunk
   面三套参与扩展名收口一处（族与能力面分层声明，Graph/FuncDiff 由族并集派生、SemChunk
   独立历史面刻意不并集）；工具描述口径经 LangsOf 派生；防漂移测试三组（族并集不变式 /
   展示名全登记 / mcpserver 描述↔langcap 集合一致）
2. **funcdiff 词法面补 JS/TS**：五语言 go/ts/js/shell/python 的函数级图 diff 全覆盖
   （reJSFunc 保守形态集：function 声明 / 箭头赋值 / 类方法含 get/set 与泛型，语句关键字
   黑名单）；Go=AST 级，shell/Python/Rust/JS/TS=词法级（BodyHash 对齐）
3. **verdict benign 判定补真缺口**：`test_*.py`（pytest 惯例此前漏判）/ `.spec.jsx` /
   `.spec.tsx` / `.test.mjs` / `.test.cjs` / `_test.sh` / `_test.bash`
4. **契约面补 `get_repo_map`**（README §3 工具表 / SKILL.md 速查 / tools.md 三处漏载）+
   工具计数 23→24；README §5.5 重写「多语言支持与语言能力矩阵」（能力×精度档+已知缺口）；
   §5.3「非 Go 变更自动跳过」限定语修正
5. repomap 装载边按族分流（shell source=RelSource、import·include=RelImport）；上游
   [oagentkit/textx#83](https://github.com/oagentkit/textx/issues/83)（polyglot 词法表缺
   shell + .mjs/.cjs/.pyw）已提票
