# argus v6.5.0 发布说明

**代号：平台配置面收口（Platform Surface Convergence）**

起因：宣传页快速开始快照被点破不对——只列 `ARGUS_GITEA_*`（Gitea-only 误导多平台用户）、
引用不存在的 `ARGUS_LLM_BASE_URL`（真源是 `OPENAI_BASE_URL`，照抄 = LLM 未配置）。顺藤摸出
平台词表五处口径互不对齐 + forgejo「被宣称支持实则配不出来」（`ARGUS_FORGEJO_*` 不存在，
requirePlatform 必 404）。

## 核心变化

1. **平台词表单一事实源**：`config.SupportedPlatforms`（gitea/forgejo/github/gitlab/gitee/
   gitcode/tencent_code）= go-git-platform SDK 注册后端全集；env 同构 `ARGUS_<平台>_*`
   （腾讯工蜂前缀 `ARGUS_TENCENT_CODE_*`），装载循环与启动校验提示由它派生
2. **forgejo/gitcode/腾讯工蜂接入面补齐**：webhook 事件词表补 gitcode（pull_request+note，
   写侧规范词）/ tencent_code（merge_request+note 族）；gitcode/工蜂为 SDK 支持、
   Argus 未实测档（文档已标注）
3. **防漂移门禁三枚**：词表 ↔ `provider.RegisteredPlatforms()` 双向相等（SDK 增删平台即
   门禁红）；事件词表覆盖词表全集；mcpserver `platformVocab` 一致性测试（mcpserver
   生产面零 internal 依赖不变）
4. **文档口径统一**：README 快速开始 / env 表（补 TOKEN_STYLE·CONDITIONAL_REQUESTS·
   WEBHOOK_EVENTS 后缀）/ 路由表 `/webhook/{platform}`；docs/index.html（修死变量、
   平台示例多平台同构）；deploy 三模板；ops-runbook 速查表补平台凭证行
5. `scripts/setup-webhook.sh` 回调路径段参数化（`ARGUS_PLATFORM`，默认 gitea；按
   `ARGUS_FORGEJO_*` 一等接入须设 forgejo——SDK Forgejo 校验器双头回退皆收）

## 部署说明

  2026-11-11 已随换芯升级在役（43 k3s 双副本）
