# argus v6.0.0 发布说明

**代号：图面/真调用边（Graph & True Call Edges）**

大版本主题：把符号图从「词法近似」升级为「消歧 + 可选类型解析级」，并让图面贯通四个消费面。设计思路借鉴 GitNexus 的 Graph RAG（**只借设计、零代码引入**——其 PolyForm Noncommercial 许可证不可商用）。

## 图演四连（v5.9.0 → v6.0.0）

| 版本 | 消费面 | 内容 |
|---|---|---|
| v5.9.0 | 外部 AI（MCP） | search_sem 命中附调用方/被调邻接行；新增 `get_trace`（≤4 跳调用链）+ `get_symbol_context`（定义+callers+callees）；工具面 21→23 |
| v5.10.0 | 数据底座 | 节点身份迁 dir 限定键（`dir.Recv.Name`，跨包同名各自成节点）；import 表消歧 + 同接收者兄弟方法；`EdgeAugmenter` 钩子 + `internal/goedges`（go/types 精确边，接口分派如实产键交存在性过滤丢弃）；`ARGUS_GRAPH_PRECISE` opt-in |
| v5.11.0 | 审查 agent 本体 | semsearch 纯图模式（nil embedder，图查询零 embedding 依赖）；R3/R4 挂 `get_trace`/`get_symbol_context`；runner 双索引互不阻断 |
| v6.0.0 | 影响面图（PR 评论） | impactview L2 callers 图优先、逐符号回退 codeintel；`Stats.CallerSource` 四档透出（graph_precise/graph_lexical/codeintel/mixed） |

## 核心能力变化

1. **同名假边根治**：节点键 `dir.Recv.Name`，跨包同名 `New()` 各自成节点；裸调用同目录优先（Go 语义正解）；import 表消歧 `pkg.F`；同接收者兄弟方法 `s.Bar()`→T.Bar
2. **可选真调用边**：`ARGUS_GRAPH_PRECISE=1` 时图边经 go/types 类型解析（`typeutil.Callee`），接口分派如实产键交存在性过滤丢弃（宁缺勿假边）；工作副本不可编译自动降级词法（失败闩 per Index，新 MR 自动重试）
3. **边质量可感知**：qa/mcpserver/R3 工具措辞随 `Precise()` 动态（词法级↔类型解析级）；影响面快照 `Stats.CallerSource` 透出边源
4. **零 embedding 依赖的图查询**：纯图模式 `NewIndex(nil)`，无 ARGUS_EMBEDDING_* 的部署也能用 get_trace/get_symbol_context

## 部署说明

- 与 v5.8.2→v5.11.0 共用部署窗口：`VERSION=v6.0.0 ./deploy/k8s43/swap-deploy.sh`（bin/argus 需 arm64 预构建）
- **ARGUS_GRAPH_PRECISE 开启前提**：43 容器内 Go 模块依赖可解析（vendor/ 或内部 GOPROXY）——先实弹验证通路，不通维持缺省关（词法档全量收益照拿）
- 新增依赖：golang.org/x/tools v0.52.0（go.sum 零变化）
