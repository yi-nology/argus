# v6.9.0 — 第三轮审计 P0/P1/P2 行为批合流发版

> 合并三轮 PR：#22（P0 批 8a621f4）+ #23（P1 批 0292d28）+ #30（P1/P2 行为批 3bd240a）。
> 第三轮代码审计路线图（Meta #21）15 项行为修复全部落地，6 项特性工程拆独立 issue 跟进（#24-#29）。

## P0 · 安全边界与数据正确性（v6.7.0 段）

- **数据迁移 fail-closed 化**（#2）：关键回写迁移失败缺省拒绝启动；`ARGUS_MIGRATION_FAIL_OPEN=1` 显式逃生门降级 warn-only。
- **统一 Authorizer**（#3）：读面跨仓越权收口——`GET /reports/:ref` / `GET /stats/overview` / `GET /repos/map` / `GET /repo-settings` 四读面 + `/findings/suppress` 写面补仓库维度判定。路由授权矩阵防漂移门禁（e2e `TestAuthzMatrixCoversIDL`）+ 跨仓 403 行为矩阵（`TestAuthzRepoDenialMatrix`）。
- **RepoMap 克隆目录哈希寻址 + token 不落盘**（#4）：目录名 = `platform-<sha256(platform|owner|repo)[:12]>`，GitLab 子组碰撞根治；clone/ls-remote 凭据走 `-c http.extraHeader` 单次注入不落盘 `.git/config`；孤儿克隆 GC。
- **AutoMigrate 纳入迁移租约**（#5）：schema 迁移在 `schema_migration:automigrate` 租约内串行，多副本并发首启不再并发 DDL。

## P1 · 多副本可靠性（v6.8.0 段）

- **迁移租约 fencing**（#6）：续约 err≠nil 或 ok=false = 失租 → 取消迁移执行 + 结果作废不写 marker；marker 落库前终检续约补 fencing 强语义。
- **Webhook 幂等回查 SQL 补 t.Kind**（#7）：7 占位符 6 实参修复，并发重复投递不再回 500。
- **在飞任务唯一约束三方言**（#8）：pg partial unique index + MySQL in_flight_key 生成列 + SQLite partial index——首审并发双建任务根治。

## P1/P2 · 行为批（v6.9.0 段）

- **事件 Outbox 跨实例分发**（#10）：多副本 SSE 事件可达——发布点双写进程内 Bus + `event_outbox` 表，每实例 fanout 环回灌本地 Bus，`Event.ID` 双源去重。
- **Token 双账本模型**（#11）：配额账（done 口径）不回退 + 真实消费账（全终态聚合）+ 独立上限 `ARGUS_REAL_TOKEN_BUDGET`。
- **审查结果一致性**（#14）：CommentDelivery 扩为副作用账本（处理事实/回帖终态/外部副作用/ref 定位四列分离）+ 每小时对账 ticker + `argus_side_effect_mismatch_total` 指标。
- **完整性门禁 R5.L**（#15）：LLM 主备降级触发史进裁决——本轮审查发生主备切换则 APPROVE demote 为 COMMENT，降级原因结构化落库并进回帖。
- **运行时指标五枚**（#16）：`argus_migration_lease_lost_total` / `argus_authz_denied_total{route,scope}` / `argus_events_dropped_total{reason}` / `argus_comment_redelivery_total` / `argus_budget_exceeded_total{ledger}`。

## 部署注意

- **Schema 变更**：新表 `event_outbox`；`comment_deliveries` 增量加列（ReplyStatus/CommentID 等）；`tasks` 表 MySQL 加 `in_flight_key` 生成列 + 唯一索引（pg/SQLite 为 partial unique index）。AutoMigrate 已纳入迁移租约，多副本滚动升级安全。
- **新环境变量**：`ARGUS_MIGRATION_FAIL_OPEN`（默认关=fail-closed）、`ARGUS_REAL_TOKEN_BUDGET`（默认 0=关）。
- **回滚锚**：镜像 `argus:v6.5.0`（43 在役上一版）。
