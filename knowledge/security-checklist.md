# 安全审查清单

## 必查项（HIGH）

### 注入防护
SQL 查询是否使用参数化？禁止字符串拼接。
用户输入是否经过校验/转义后才进入命令/查询？
模板渲染是否自动转义？禁止 `v-html` / `dangerouslySetInnerHTML`。

### 认证与授权
API 端点是否都有认证中间件？
权限校验是否在服务端执行？禁止仅前端校验。
Token/密钥是否硬编码？应从环境变量/配置中心读取。
Session 是否有超时/续签机制？

### 数据保护
敏感数据（密码/Token/密钥）是否加密存储？
日志中是否脱敏？禁止打印完整 Token/密码。
文件上传是否校验类型/大小/路径？

### 并发与资源
数据库连接是否设置超时和最大连接数？
HTTP 客户端是否设置超时？
goroutine 是否有退出机制？禁止无限 goroutine。

## 建议项（MEDIUM）

错误信息是否泄露内部实现细节？
依赖版本是否有已知漏洞（govulncheck）？
CORS 配置是否过于宽松？
是否使用了不安全的随机数（math/rand vs crypto/rand）？

## 审查方法

静态分析：govulncheck / go vet / golangci-lint。
代码走读：关注数据流（输入→处理→输出）。
配置审查：环境变量/配置文件中的敏感信息。
依赖审计：go.mod 中的第三方库版本。
