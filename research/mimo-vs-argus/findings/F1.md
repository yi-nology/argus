# F1: Xiaomi MiMo model family

## Findings

### [1] Xiaomi's first public MiMo LLM family is MiMo-7B (MiMo-7B-Base / SFT / RL-Zero / RL / RL-0530), released May 2025 as a reasoning-focused open-source series under Apache-2.0.
- quote: "In this work, we present MiMo-7B, a series of models trained from scratch and born for reasoning tasks... We open-source MiMo-7B series, including checkpoints of the base model, SFT model, RL model trained from base model, and RL model trained from the SFT model."
- url: https://github.com/XiaomiMiMo/MiMo
- source_type: primary
- published: 2025-05-12 (arXiv v1); README update 2025-05-30
- confidence: high

### [2] MiMo-7B-Base was pretrained on ~25 trillion tokens with Multi-Token Prediction (MTP); post-training used 130K rule-verifiable math/code problems and a test-difficulty-driven code reward.
- quote: "Overall, MiMo-7B-Base is pre-trained on approximately 25 trillion tokens. We incorporate Multiple-Token Prediction as an additional training objective... We curate 130K mathematics and code problems as RL training data, which can be verified by rule-based verifiers."
- url: https://arxiv.org/abs/2505.07608
- source_type: primary
- published: 2025-05-12 (v1), 2025-06-05 (v2)
- confidence: high

### [3] Xiaomi claims MiMo-7B-RL matched OpenAI o1-mini; official scores include MATH-500 95.8, AIME 2024 68.2, AIME 2025 55.4, LiveCodeBench v5 57.8, GPQA-Diamond 54.4 (temp=0.6, multi-run averages for some).
- quote: "MiMo-7B-RL... demonstrates superior performance on both mathematics and code reasoning tasks, matching the performance of OpenAI o1-mini."
- url: https://github.com/XiaomiMiMo/MiMo
- source_type: primary
- published: 2025-05-12
- confidence: high

### [4] A May 30, 2025 checkpoint MiMo-7B-RL-0530 scaled SFT data ~500K→6M and RL window 32K→48K, lifting AIME24 from 68.2 to 80.1 (claimed to surpass DeepSeek R1's 79.8 on that benchmark).
- quote: "We scaled the SFT dataset from approximately 500K to 6M instances and continuously expanding the RL training window size from 32K to 48K, the performance of MiMo-7B-RL-0530 on AIME24 can be continuously improved and eventually surpass that of DeepSeek R1 (79.8)."
- url: https://github.com/XiaomiMiMo/MiMo
- source_type: primary
- published: 2025-05-30
- confidence: high

### [5] MiMo-VL-7B (SFT + RL) is Xiaomi's open-source vision-language line (arXiv 2506.03569, June 4, 2025): native-resolution ViT + MLP projector + MiMo-7B LM backbone; four-stage pretraining on 2.4T tokens plus Mixed On-policy RL (MORL).
- quote: "MiMo-VL-7B comprises (1) a native resolution ViT encoder... (2) an MLP projector... and (3) our MiMo-7B language model... Our training combines four-stage pre-training (2.4 trillion tokens) with Mixed On-policy Reinforcement Learning (MORL)."
- url: https://arxiv.org/abs/2506.03569
- source_type: primary
- published: 2025-06-04
- confidence: high

### [6] MiMo-VL-7B-RL official abstract claims: outperforms Qwen2.5-VL-7B on 35/40 tasks, OlympiadBench 59.4 (surpassing models up to 78B), OSWorld-G 56.1 (even vs GUI-specialized UI-TARS); architecture remains Qwen2.5-VL-compatible for deployment.
- quote: "MiMo-VL-7B-RL outperforms Qwen2.5-VL-7B on 35 out of 40 evaluated tasks, and scores 59.4 on OlympiadBench... For GUI grounding applications, it sets a new standard with 56.1 on OSWorld-G, even outperforming specialized models such as UI-TARS."
- url: https://arxiv.org/abs/2506.03569
- source_type: primary
- published: 2025-06-04
- confidence: high

### [7] MiMo-V2-Flash is a 309B-total / 15B-active sparse MoE designed for high-speed reasoning and agentic workflows: hybrid SWA:GA attention (5:1, 128-token window), ~6× KV-cache reduction, 27T-token FP8 pretraining, 256k context, 3-layer MTP (~0.33B/block) claimed to triple generation speed.
- quote: "MiMo-V2-Flash is a Mixture-of-Experts (MoE) language model with 309B total parameters and 15B active parameters... Interleaves Sliding Window Attention (SWA) and Global Attention (GA) with a 5:1 ratio and an aggressive 128-token window... Trained on 27T tokens using FP8 mixed precision... The context window supports up to 256k length."
- url: https://huggingface.co/XiaomiMiMo/MiMo-V2-Flash
- source_type: primary
- published: tech report linked as 2026-01-08 on mimo.xiaomi.com; HF model card current
- confidence: high

### [8] MiMo-V2-Flash post-training headline agent/reasoning scores (official card): SWE-Bench Verified 73.4, SWE-Bench Multilingual 71.7, Terminal-Bench 2.0 38.5, AIME 2025 94.1, LiveCodeBench-v6 80.6, BrowseComp 45.4 (58.3 with context management), τ²-Bench 80.3; recommended agentic sampling temp=0.3 with tool-call parser `mimo`.
- quote: "SWE-Bench Verified 73.4... Terminal-Bench 2.0 38.5... AIME 2025 94.1... LiveCodeBench-v6 80.6... temperature=0.3 for agentic taks (e.g., vibe-coding, tool-use)."
- url: https://huggingface.co/XiaomiMiMo/MiMo-V2-Flash
- source_type: primary
- published: unknown (card current as of research date 2026-09-17)
- confidence: high

### [9] Agentic intelligence is trained, not just prompted: Xiaomi scaled agentic RL with >100,000 verifiable GitHub-issue tasks on a Kubernetes cluster (>10,000 concurrent pods, ~70% env setup success), plus Multi-Teacher On-Policy Distillation (MOPD) and infra like Rollout Routing Replay (R3) for MoE train/infer consistency.
- quote: "We utilize real-world GitHub issues to create over 100,000 verifiable tasks. Our automated pipeline maintains a Kubernetes cluster capable of running over 10,000 concurrent pods with a 70% environment setup success rate... MOPD... formulates knowledge distillation as a reinforcement learning process."
- url: https://huggingface.co/XiaomiMiMo/MiMo-V2-Flash
- source_type: primary
- published: MOPD paper listed 2026-06-29 on mimo.xiaomi.com
- confidence: high

### [10] MiMo-V2.5 (official blog dated April 22, 2026) is a native omnimodal 310B/15B sparse MoE supporting text/image/video/audio with up to 1M-token context; trained on ~48T tokens with context extended 32K→256K→1M during agentic SFT/RL.
- quote: "Today, we are releasing MiMo-V2.5... MiMo-V2.5 is a 310B-parameter Sparse MoE model (15B active) trained on 48T tokens... supports up to 1 million tokens of context... the context window is progressively extended from 32K to 256K to 1M."
- url: https://mimo.xiaomi.com/mimo-v2-5
- source_type: primary
- published: 2026-04-22
- confidence: high

### [11] MiMo-V2.5 multimodal architecture details: inherits MiMo-V2-Flash hybrid attention (5:1 SWA:GA, window 128); 729M-param ViT (28 layers: 24 SWA + 4 Full); 261M audio encoder initialized from MiMo-Audio-Tokenizer; 329M 3-layer MTP; base checkpoint context 256K, instruct checkpoint 1M; MIT license; FP8 weights.
- quote: "Equipped with a 729M-param Vision Transformer (ViT)... a dedicated audio encoder initialized from the weights of MiMo-Audio... Context Length: Up to 1M tokens... Modalities: Text, Image, Video, Audio."
- url: https://huggingface.co/XiaomiMiMo/MiMo-V2.5
- source_type: primary
- published: 2026-04-22 (blog); HF card current
- confidence: high

### [12] MiMo-V2.5-Pro is the flagship text/agentic model: 1.02T total / 42B active, 1M context, hybrid SWA:GA 6:1; official HF eval results include SWE-bench Verified 78.9, SWE-bench Pro 57.2, Terminal-Bench 2.0 68.4, GSM8K 99.6, GPQA-Diamond 66.7 (base-table); GraphWalks long-context claim: Pro still scores 0.56 BFS / 0.92 Parents at 512k while V2 collapses to 0.00 at 1M.
- quote: "MiMo-V2.5-Pro is an open-source Mixture-of-Experts (MoE) language model with 1.02T total parameters and 42B active parameters... with up to 1M tokens context length... designed for the most demanding agentic, complex software engineering, and long-horizon tasks."
- url: https://huggingface.co/XiaomiMiMo/MiMo-V2.5-Pro
- source_type: primary
- published: blog listed on mimo.xiaomi.com; citation year 2026
- confidence: high

### [13] Official HF-aggregated coding/agent scores for MiMo-V2.5: SWE-bench Pro 56.1, Terminal-Bench 2.0 65.8, Claw-Eval General Pass³ 62.1 (multimodal subset only 23.8); official blog frames V2.5 as matching V2.5-Pro on internal MiMo Coding Bench "at half the cost."
- quote: "ScaleAI/SWE-bench_Pro... 56.1... terminalbench 2... 65.8... In our internal MiMo Coding Bench, MiMo-V2.5 delivers strong results... matching MiMo-V2.5-Pro at half the cost."
- url: https://huggingface.co/XiaomiMiMo/MiMo-V2.5
- source_type: primary
- published: 2026-04-22
- confidence: high

### [14] Public model family spans ~25 HF checkpoints under org XiaomiMiMo: MiMo-7B* (8B), MiMo-VL-7B* (incl. 2508 refresh), MiMo-Audio-7B + Audio-Tokenizer, MiMo-Embodied-7B, MiMo-V2-Flash* (310B), MiMo-V2.5 / V2.5-Pro / DFlash / FP4-DFlash (311B–1T), MiMo-V2.5-ASR; official site also lists V2.5-TTS series and papers (HySparse, ARL-Tangram, MOPD).
- quote: "models 25... XiaomiMiMo/MiMo-V2.5... XiaomiMiMo/MiMo-V2.5-Pro... XiaomiMiMo/MiMo-V2-Flash... XiaomiMiMo/MiMo-Embodied-7B... XiaomiMiMo/MiMo-V2.5-ASR..."
- url: https://huggingface.co/models?author=XiaomiMiMo
- source_type: primary
- published: unknown (org page as of 2026-09-17)
- confidence: high

### [15] Model↔agent product relationship: official site presents MiMo as "Xiaomi's universal smart platform" with Product → MiMo Code; GitHub org's top repo is XiaomiMiMo/MiMo-Code (~13.2k stars, TypeScript, MIT) tagged "MiMo Code: Where Models and Agents Co-Evolve"; related blog "MiMo Code: Scaling Coding Agents to Long-Horizon Tasks" covers computation/memory/evolution; API + AI Studio surfaces at platform.xiaomimimo.com and aistudio.xiaomimimo.com. Deployment cards expose `--tool-call-parser mimo` and `--reasoning-parser mimo`/`qwen3` for SGLang/vLLM.
- quote: "MiMo Code: Where Models and Agents Co-Evolve... We are building MiMo, Xiaomi's universal smart platform... Product MiMo Code... Xiaomi MiMo API Platform... Xiaomi MiMo Studio."
- url: https://github.com/XiaomiMiMo
- source_type: primary
- published: GitHub org listing as of 2026-09-17; product page https://mimo.xiaomi.com/
- confidence: high

### [16] Recommended production system identity for self-hosted MiMo-V2-Flash is explicit: English/Chinese system prompts name the model "MiMo, an AI assistant developed by Xiaomi," knowledge cutoff December 2024; tool-use in thinking mode requires persisting `reasoning_content` alongside `tool_calls` across multi-turn agent conversations.
- quote: "You are MiMo, an AI assistant developed by Xiaomi... your knowledge cutoff date is December 2024... In the thinking mode with multi-turn tool calls, the model returns a `reasoning_content` field alongside `tool_calls`. To continue the conversation, the user must persist all history `reasoning_content` in the `messages` array of each subsequent request."
- url: https://huggingface.co/XiaomiMiMo/MiMo-V2-Flash
- source_type: primary
- published: unknown (card current)
- confidence: high
