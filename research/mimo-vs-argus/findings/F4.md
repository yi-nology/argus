# F4: Public reception and competitive positioning

## Findings

### [1] Xiaomi self-reports MiMo-V2-Flash post-training at near-frontier coding/agent scores but clearly below Claude/Gemini on hard reasoning and Terminal-Bench
- quote: "SWE-Bench Verified … MiMo-V2 Flash 73.4 … Claude Sonnet 4.5 77.2 … GPT-5 High 74.9 … HLE (no tools) 22.1 … Gemini-3.0 Pro 37.5 … Terminal-Bench 2.0 38.5 … Gemini 54.2"
- url: https://huggingface.co/XiaomiMiMo/MiMo-V2-Flash
- source_type: primary
- published: 2025-12 (model card updated Jul 9; tech report cited 2025)
- confidence: high

### [2] HF-submitted third-party evals for MiMo-V2.5 place it mid-pack on agent coding (SWE-bench Pro 56.1, Terminal-Bench 2.0 65.8) with weak multimodal agent scores on Claw-Eval
- quote: "ScaleAI/SWE-bench_Pro · SWE Bench Pro … 56.1 … terminalbench_2 … 65.8 … Claw-Eval … General … 62.1 … Multimodal … 23.8 … Multi Turn … 63.2"
- url: https://huggingface.co/XiaomiMiMo/MiMo-V2.5
- source_type: primary
- published: unknown (eval discussion posts; model card updated Jul 9)
- confidence: high

### [3] Vendor materials claim MiMo Code + MiMo-V2.5-Pro beats Claude Code + Sonnet 4.6, but only Claude is benchmarked; independent Terminal-Bench 2.0 leaderboard shows Codex CLI well above MiMo's self-reported score
- quote: "MiMo Code paired with MiMo-V2.5-Pro outperformed Claude Code paired with Claude Sonnet 4.6 on all three evaluations … SWE-bench Verified: 82% vs. 79% … Terminal Bench 2: 73% vs. 69% … OpenAI's Codex CLI running GPT-5.5 scores 82.2% — roughly nine points above MiMo Code's self-reported 73%"
- url: https://venturebeat.com/technology/xiaomis-new-open-source-agentic-ai-coding-harness-mimo-code-beats-claude-code-at-ultra-long-200-step-tasks
- source_type: secondary
- published: 2026-06-11
- confidence: high

### [4] VentureBeat and Xiaomi both flag the benchmarks as vendor self-reported; harness-only gains are claimed at ~5 pts (SWE-bench Pro 62% vs 57% with same model), and long-horizon advantage is claimed only past 200 steps (>65% win rate from 576-dev / 1,213-pair A/B)
- quote: "Running the same MiMo-V2.5-Pro model in both harnesses, MiMo Code scored 62% on SWE-bench Pro versus 57% for Claude Code … past 200 steps, MiMo Code's win rate rose above 65% … these are vendor self-reported numbers that haven't been independently verified"
- url: https://venturebeat.com/technology/xiaomis-new-open-source-agentic-ai-coding-harness-mimo-code-beats-claude-code-at-ultra-long-200-step-tasks
- source_type: secondary
- published: 2026-06-11
- confidence: high

### [5] Independent hard-coding benchmark DeepSWE does not list MiMo among current v1.1 leaders; HN users cite MiMo-v2.5-Pro at 19% vs frontier 63–74%
- quote: "For reference, Mimo-v2.5-Pro scored 19% on DeepSWE 1.1. … Fable scores 70%, Kimi K3 69%, Astra 74% (all on max effort)."
- url: https://hn.algolia.com/api/v1/items/49732270 (comment 49734155); leaderboard: https://deepswe.datacurve.ai/blog/deepswe-v1-1
- source_type: community
- published: 2026-09-16 (comment); DeepSWE v1.1 blog 2026-06-14, tasks updated 2026-09-03
- confidence: medium

### [6] Developer community consensus on MiMo models is "cheap and adequate-to-good, not frontier": praised as first Chinese model that "feels like Sonnet" at fraction of cost; criticized for overthinking, forgetfulness, conservative implementations, and basic mistakes
- quote: "the first Chinese model that I've tried where I really though why should I use Claude Sonnet … this feels like Sonnet … If I had one complaint, the v2.5.0-Pro model thinks too much."
- url: https://news.ycombinator.com/item?id=48490826 (HN MiMo Code thread, comments 48492029 context / 48495480+)
- source_type: community
- published: 2026-06-11
- confidence: high

### [7] Long-form practitioner feedback describes MiMo-V2.5-Pro as a "somewhat forgetful senior engineer" — capable and low-scrutiny on defined tasks, but not great at multi-tasking and "extremely conservative" in code; some users call 2.5 an underperformer and cancel subscriptions
- quote: "I had used 2.5-pro for a hefty chunk of development, and found it to work like a somewhat forgetful senior engineer who was new to my project. … I found MiMo-V.2.5-pro to be extremely conservative, implementing minimal solutions."
- url: https://news.ycombinator.com/item?id=49732270 (thread on MiMo 2.6 live post-training dashboard)
- source_type: community
- published: 2026-09-16
- confidence: high

### [8] Cost-performance is MiMo's strongest public positioning: API pricing is among the cheapest frontier-class options; practitioners report using MiMo as a cheap executor under Claude Code/Codex planners, and some rate its ROI "an order of magnitude better" than DeepSeek/GLM alternatives despite quality gaps
- quote: "MiMo-V2.5 starts at $0.40 per million input tokens and $2.00 per million output tokens, while V2.5-Pro runs $1.00/$3.00 … You can use Codex as an orchestrator and claude code via mimo/deepseek api as executor."
- url: https://venturebeat.com/technology/xiaomis-new-open-source-agentic-ai-coding-harness-mimo-code-beats-claude-code-at-ultra-long-200-step-tasks ; https://hn.algolia.com/api/v1/search?query=MiMo%20Claude%20Code&tags=comment
- source_type: secondary
- published: 2026-06-11 (VB); HN comments 2026-05-27 through 2026-09-17
- confidence: high

### [9] MiMo Code (agent product) drew high HN engagement (557 pts / 315 comments on launch) and ~13.2k GitHub stars, but reception is split: OpenCode-fork controversy, default-on telemetry to tracking.miui.com, "unlimited context" marketing challenged, and recurring "risk control" API blocks
- quote: "it does have telemetry, enabled by default, that sends metrics to tracking.miui.com … telemetry enabled by default and named \"analysis\" is not great." … "Claude Code 还在老老实实卷 1M 上下文，小米 MiMoCode 已经用\"无限上下文\"遥遥领先。是不是缺了一行小字"
- url: https://news.ycombinator.com/item?id=48490826 ; https://github.com/XiaomiMiMo/MiMo-Code/issues/295
- source_type: community
- published: 2026-06-11 (HN launch); issue #295 opened 2026-06-11
- confidence: high

### [10] Competitive positioning vs Claude Code / Codex / Cursor is dual-track: MiMo ships its own MIT-licensed OpenCode-fork harness (MiMo-Code) plus models usable inside Cursor/Cline/Zed; community often prefers Claude Code as harness while running MiMo models inside it, and independent reviewers rate MiMo Code's UX distinct but the model "fine" not best-in-class
- quote: "MiMo Code is just cute as hell. … It also is not a direct copy of Claude Code. … MiMo has the cheapest tokens for a 1T+ model in the game, though DeepSeek and GLM are better models, MiMo is fine."
- url: https://hn.algolia.com/api/v1/search?query=MiMo%20Claude%20Code&tags=comment (SwellJoe comments, 2026-07-03 and 2026-08-05); README: https://github.com/XiaomiMiMo/MiMo-Code
- source_type: community
- published: 2026-07-03 / 2026-08-05 (HN); README as of 2026-09-17
- confidence: high

### [11] Ecosystem maturity signals are mixed but real: large HF downloads (MiMo-V2.5 ~302k/month) and active multi-modal portfolio, yet agent product shows 738 open issues, known platform reliability problems (risk-control 400s), config-drift performance degradation warnings, Windows CJK issues, and OpenRouter availability complaints
- quote: "Downloads last month 302,386" … "Error: Request blocked by risk control status 400 · non-retryable" … "If you downloaded MiMo-V2.5 before this commit … Using the outdated config may lead to degraded model performance."
- url: https://huggingface.co/XiaomiMiMo/MiMo-V2.5 ; https://github.com/XiaomiMiMo/MiMo-Code/issues?q=is%3Aissue+sort%3Acomments-desc ; https://github.com/XiaomiMiMo/MiMo-Code/issues/1409
- source_type: primary
- published: unknown (HF stats as of fetch 2026-09-17); issues Jun–Jul 2026
- confidence: high

### [12] Media framing positions Xiaomi MiMo as part of the Chinese open-weight / cheap-token wave (DeepSeek/Qwen/Kimi playbook) led by ex-DeepSeek R1 researcher Fuli Luo, with deliberate Claude Code as sole named competitor — a telling choice given Codex/Gemini CLI gaps
- quote: "The effort is led by Fuli Luo, a veteran of DeepSeek's disruptive R1 project … Xiaomi notably did not publish comparisons against OpenAI's Codex or Google's Gemini CLI — Claude Code is the sole named competitor throughout its materials"
- url: https://venturebeat.com/technology/xiaomis-new-open-source-agentic-ai-coding-harness-mimo-code-beats-claude-code-at-ultra-long-200-step-tasks
- source_type: secondary
- published: 2026-06-11
- confidence: medium
