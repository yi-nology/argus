分层（argus-service）

L1 bootstrap 组合根（装配一切，无人 import 它）
L2 runner / service / poller / worker / mcpserver（编排与入口）
L3 workflow / poster / qa / storage / sastscan / effect / egress …
L4 plugin 契约单源 + domain + learning
L0 config / obs（纯底座）

依赖由 architecture-policy.yaml 钉住，make arch 可执行门禁（分层白名单 / 组合根单向 / 词表门禁）。

工程原则

fail-closed 优先

无 CI 不合并、缺票不修复、无 token 不服务、未知态先对账。

确定性裁决

R5 真值表零 LLM；路由/去重/合并指纹全是确定性 Go 代码。

受控远端写

三类写全部 preview → confirm，绑定 expected_remote_head。

版本一处源

sync-version 五处同源；CI check-version-consistency 钉住。
