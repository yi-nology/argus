Skills · 让 AI 直驱 Argus

装进你的 AI 客户端（Claude Code / ZCode / Cursor），AI 就知道怎么发起审查、读意见、执行修复。

argus-mcp

AI agent 驱动 Argus 的完整工作流：何时调哪个工具、失败降级、安全边界。配合 MCP 24 工具。

argus-precommit

提交前预审闭环：review -async 提交 diff 预审 + poll 轮询结论，审查左移倒灌 coding agent。

一键安装

curl -fsSL https://raw.githubusercontent.com/yi-nology/argus-service/main/scripts/install-skills.sh | bash

工具说明

ask_argus最新结论 / 基于报告追问
