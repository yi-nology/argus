Deploy

三种形态，一套产物

单机 compose 起步，Helm 上 HA，裸 K8s 可控到底。发布二进制带 checksums 与 SBOM。

docker-compose（单机）

git clone https://github.com/yi-nology/argus.git && cd argus/deploy/docker-compose
cp .env.example .env && chmod 600 .env
docker compose up -d
curl http://127.0.0.1:8899/healthz

Helm（K8s HA）

cd deploy/helm
helm lint argus
helm install argus argus -n argus --create-namespace

缺省拓扑：双副本 RollingUpdate（maxUnavailable=0）· PostgreSQL + PVC · Migration Job 先行 · 备份 Cron + 恢复演练 Job。

发布二进制

scripts/release.sh v8.2.0
# → argus_linux_amd64 / argus_linux_arm64 + checksums.txt + sbom.json

GHCR 镜像 ghcr.io/yi-nology/argus · Releases 下载校验。

部署后自检

scripts/preflight.sh --live
